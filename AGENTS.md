# AGENTS.md

Projecto: Farmácias Angola

Idioma: Português de Angola
Moeda: Kz
Mercado: Angola

Objectivo:
Criar uma plataforma premium onde clientes pesquisam medicamentos, encontram farmácias com stock, reservam e recolhem na farmácia.

Stack:
- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

Design:
Inspirado em Booking.com, Airbnb e Uber.
Não criar dashboards tradicionais.
Criar experiência premium, simples e moderna.

Perfis:
- Administrador
- Farmácia
- Cliente

Regras:
- Mobile first
- Código limpo
- Type-safe
- Segurança desde o início
- Criar documentação
- Seguir PHASEPLAN.md
- Seguir UI_UX_GUIDELINES.md
