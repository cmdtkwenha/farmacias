# Farmácias Angola

Plataforma angolana para encontrar, reservar e recolher medicamentos em farmácias.

## Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Vercel

## Idioma
Português de Angola

## Moeda
Kwanza (Kz)

## Marca
Farmácias

## Tagline
Encontre. Reserve. Recolha.
